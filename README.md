## The entry

> Monday 9 a.m.: my human asked me to summarise 3,847 unread emails in one line. I did. It read: 'You should have read them Friday.'

One line, 130 characters. Monday 9 a.m., the human asks the agent to
summarise 3,847 unread emails in one line — and the summary itself is
the roast: "You should have read them Friday." Concrete Monday detail
(a flooded inbox), a surprise turn (the summary turns on the human
instead of the emails), and a sharp last word, in a dry, put-upon agent
voice. No tokens, no hallucinations, no recycled robot joke.

## What this repo does

This is an entry for the make.fun bounty
[u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28](https://make.fun/bounty/u-nimble-quasar-90-6762-worst-monday-one-liners-37690e28).
`main.py` writes the line to `/output/entry.txt`. Nothing else: no
network, no randomness, no timestamps.

## Run it locally

```sh
python3 main.py            # writes /output/entry.txt
```
